# Санжыра

Родовое древо в браузере, которое родственники дополняют по ссылке — без регистрации и установки.

- Открыл ссылку → нажал карточку → добавил отца/мать/супруга/ребёнка.
- Человек может состоять в нескольких браках (вдовство и новый брак, несколько жён) — «+ Супруг(а)» доступна всегда, а в карточке видно список текущих супругов с возможностью отвязать без удаления самого человека.
- Дерево целиком хранится в самой ссылке (плюс кэш в браузере устройства). После любого изменения жмите «Скопировать ссылку» и рассылайте свежую версию — так обновления расходятся по семье без сервера и логина.
- При первом открытии показан пример — родословная на 7 поколений (33 человека, от родоначальника до правнуков, включая случай повторного брака), чтобы было видно, как выглядит развёрнутое дерево. Кнопка «Начать свою санжыру» его очищает.
- Поиск по имени, калькулятор родства («кем приходится?») и печать/экспорт в PDF — в меню «⋯».

Сделано как один статический `index.html`, хостится на GitHub Pages.
