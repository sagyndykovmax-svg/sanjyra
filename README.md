# Санжыра

Родовое древо в браузере, которое родственники дополняют по ссылке — без регистрации и установки.

- Открыл ссылку → нажал карточку → добавил отца/мать/супруга/ребёнка.
- Дерево целиком хранится в самой ссылке (плюс кэш в браузере устройства). После любого изменения жмите «Скопировать ссылку» и рассылайте свежую версию — так обновления расходятся по семье без сервера и логина.
- При первом открытии показан пример на 6 человек — кнопка «Начать свою санжыру» его очищает.

Сделано как один статический `index.html`, хостится на GitHub Pages.
